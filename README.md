## 📝 Validaciones Aplicadas al Formulario
* **Nombre:** Obligatorio (`required`), mínimo 3 caracteres (`minlength="3"`).
* **Correo electrónico:** Estructura nativa requerida (`type="email"`).
* **Teléfono:** Formato exacto de 9 dígitos numéricos (`pattern="[0-9]{9}"`).
* **Motivo:** Selección obligatoria con opción real (`required`).
* **Mensaje:** Mensaje mínimo de 10 caracteres (`minlength="10"`).
* **Fecha (Reto):** Selector de fecha interactivo (`type="date"`).
* **Términos:** Aceptación obligatoria del checkbox (`required`).
